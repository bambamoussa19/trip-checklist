# Trip Destination Check List

An interactive packing-checklist website built for a Week 5 web development project.

**What it does**
- Loads a list of 8 trip items from a JavaScript array when the page opens
- Dynamically creates a checkbox + label for each item inside the list div
- Live-updates a "Checked items" tally every time a box is checked or unchecked

**Tech:** HTML, CSS, JavaScript (no frameworks)

**Files**
- `trip.html` — page structure
- `css/styles.css` — layout and styling
- `js/main.js` — checklist builder + tally counter
- `images/portugal.jpg` — destination photo

**How to run:** open `trip.html` in any browser.
